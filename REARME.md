# Sistema de Orientación y Registro de Atenciones

## Curso
Fundamentos de Programación

## Caso práctico
Sistema de orientación y registro de atenciones para el módulo de soporte académico.

## Lenguaje
C#

## Descripción
Programa de consola desarrollado en C# para registrar solicitudes de estudiantes,
validar sus datos y clasificar la prioridad de atención mediante funciones.

## Requerimientos
El sistema permite:
- Registrar solicitudes.
- Validar el código del estudiante.
- Validar el tipo de consulta.
- Asignar prioridad.
- Mostrar el resumen de las solicitudes.
- Registrar al menos tres solicitudes.
- Realizar pruebas de funcionamiento.
