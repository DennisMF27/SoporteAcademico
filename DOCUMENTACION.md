
# Sistema de Soporte Académico

| Requerimiento | Función o elemento |

## Descripción de las funciones

- ValidarCodigoEstudiante: comprueba que el código no esté vacío y tenga la longitud mínima.
- ValidarTipoConsulta: verifica que el tipo esté entre los valores permitidos.
- MostrarMenu: presenta las opciones disponibles.
- AsignarPrioridad: devuelve la prioridad según el tipo de consulta.
- ValidarTextoObligatorio: comprueba que un texto tenga contenido.
- MostrarResumen: presenta los datos de la solicitud usando parámetros.

## Pruebas

Se realizaron pruebas de validación de código, nombre, tipo de consulta, descripción y registro exitoso.

## Conclusión

El programa permite registrar solicitudes académicas, validar los datos ingresados, asignar prioridades y mostrar un resumen de cada solicitud.
